# A Succubus Tale R2 1.1.0 — 説明書

**バージョン 1.1.0** · 日本語 / English (see `README.md`) · OStim統合サキュバスMOD（Skyrim SE）

**Nexus:** https://www.nexusmods.com/skyrimspecialedition/mods/194039 · **ソース:** https://github.com/Nyannco/A-Succubus-Tale-R2

## 概要
**A Succubus Tale R2（ASTR2）** は、[OStim NG](https://www.nexusmods.com/skyrimspecialedition/mods/OStim) と統合したサキュバス・プレイMODです。プレイヤーはサキュバスとなり、誘惑と **OStimシーン** で相手から **淫魔力（Essence）** を吸い取って成長し、相手を魅了して眷属（サーヴァント）にしたり、亡骸を蘇らせて僕（しもべ）にしたりできます。

**A Succubus Tale - Remake**（作者 ShMinitmMan・[Nexus mods/107235](https://www.nexusmods.com/skyrimspecialedition/mods/107235)）への深いリスペクトから生まれた、OStim統合・機能拡張版です。

## 作者より
このMODは、CaptainHubs氏の『A Succubus Tale』と、ShMinitmMan氏の『A Succubus Tale - Remake』への敬意と感謝から生まれたものです。素晴らしい原作がなければ、このMODは存在しませんでした。心から感謝申し上げます。

このMODはもともと自分用に作ったものを、そのままの形で公開しています。なるべく元々の機能を壊さず、バグがないように作ったつもりですが、至らぬところがあるかもしれません。バグにはなるべく迅速に対応いたしますので、コメント等お気軽に書き込んでください。
新規機能はだいぶ自分勝手に作っています。威力や上昇量は、皆様の環境に合わせてMCMで調整して遊んでいただけると幸いです。
サキュバスの物語を楽しんでいただけたら嬉しく思います。

## 主な機能
- **サキュバス化とレベル成長** — 淫魔力を集めてサキュバスとして成長。レベルに応じてマジカ／体力／スタミナの最大値・再生・話術が自動的に上がります。
- **淫魔力ドレイン** — 吸収呪文で相手の体力を淫魔力に変換。OStimシーン中のオーガズムでも吸収し、フィニッシュで吸い尽くすことも。高レベルでは**範囲ドレイン**で周囲を一度に吸えます。
- **魅了・サーヴァントシップ** — 魅了で相手を陥落させてOStimシーンへ。関係を積み重ねて **5段階（獲物／虜／僕／眷属／愛玩）** に育て、隷属同期でゲーム本来の好感度も取り込みます。
- **甘屍招来（Sweet Vassal）** — 亡骸を蘇らせて僕（ヴァッサル）に。低レベルでは死霊として、高レベル（Lv9）では生者として蘇り、OStimシーン参加や従者化も可能に。
- **Hスキル** — 行為ごとの上達度が、興奮・淫魔力の採取量・関係・スペル威力などに補正として効きます。
- **夢魔誘襲（Nightmare Embrace）** — 眠っている相手を夢の中で襲います（成功率はレベル連動）。
- **淫紋・淫魔晶・甘露丹** — 淫紋（体に浮かぶ紋様）の表示、淫魔晶（Essence Shard）への淫魔力の封入、甘露丹（Sweet Elixir）による「火種」のストック。
- **MCMメニュー** — 機能のオンオフ、威力の調整、ステータス確認、サーヴァント一覧、淫紋設定などを細かく設定できます。

## インストール
1. 先に必須MOD（特に OStim NG）を導入し、正常動作を確認します。
2. MOD管理ツール（MO2 / Vortex）で本MODを導入します。
3. **インストーラー（FOMOD）で表示言語を選びます** — デフォルトは英語です。日本語で遊ぶ場合は「日本語」を選択してください（英語版ゲームでも日本語で表示されます）。英語のままなら英語で表示されます。
4. ゲーム起動後、MCMで設定を確認します。

## アンインストール
プレイ途中での撤去は Skyrim の仕様上おすすめしませんが、外す場合は次の手順で行ってください。
1. MCMの「MODコンフィグ」でサキュバスモードを **OFF（人間化）** にします＝呪文・パーク・淫紋・ステータス補正・ヴァッサルなどが解除されます。
2. その状態で **セーブ** します（できれば新しいセーブスロットに）。
3. ゲームを終了し、MOD管理ツール（MO2 / Vortex）で本MODを **削除** します。
4. （任意・より綺麗にしたい場合）本MODが生成したデータフォルダを **丸ごと削除** してください。**同名でもフォルダが違えば別MODの物です**＝下記の **1フォルダだけ** 消せばOKです。
   - `Data\SKSE\Plugins\StorageUtilData\ASuccubusTaleR2\`（丸ごと＝`Records.json`＝生涯記録／`Config.json`＝設定のバックアップ）
   - ※**MO2 の場合**、このフォルダは通常ゲームの `Data` ではなく **overwrite** の中にあります（`overwrite\SKSE\Plugins\StorageUtilData\ASuccubusTaleR2\`）。
5. （任意）**SKSEログフォルダ**（「不具合報告のしかた」の節の場所＝MCMの「格納場所」で確認できます）に、本MODが作った次のファイルが残ることがあります。気になる場合は削除してください（無ければそのままでOK）：
   - `ASTR2SKSE.log`（SKSEプラグインログ）／`ASTR2_BugReport.txt`（不具合報告を作成した場合）／`ASTR2_CatalogDump.txt`（シーンカタログ）

## 使い方
### 始め方（サキュバスになる）
- **新規ゲームを開始し、そのデータで初めてプレイすると、「サキュバスになるか？」を尋ねるポップアップが自動で表示されます。** ここで承諾するとサキュバスとして目覚めます。
- **ポップアップが出なかった場合や、後から切り替えたい場合は、MCMのトリガーからいつでもサキュバスモードのオン／オフができます。**

### 人間に戻る（サキュバスモードOFF）とどうなる
サキュバスモードをOFF（人間化）にしても、**進行データは破棄されません**。再びサキュバスに戻れば元通りになります。

- **保持されるもの（人間化しても消えない）**：サキュバスのレベル・経験値・各種記録（総獲得・ドレイン量・相手の記録など）・サーヴァントとの関係。
- **人間の間は一時的にOFFになるもの（サキュバスに戻ると復活）**：レベル連動ステータス（マジカ／体力／スタミナの最大値・再生・話術）、スキル経験値ボーナス、サキュバスの呪文、淫紋の表示、ドレインのオン状態。現在の淫魔力は初期値（400）に戻ります。

## 既知の問題・注意点
- **OStimシーン開始後に近づいてきた敵の攻撃でクラッシュすることがあります。** 開始時には「戦闘中／近くに敵がいる」とシーンを始めないようガードしていますが、**シーンが始まった後に歩いて来た敵**までは対処できていません。そうした敵の攻撃がシーン中のアクターに当たった瞬間にネイティブクラッシュが起こり得ます（人目のない場所での使用を推奨）。
- **古いバージョンの OStim が混在すると、OStimシーン中にフリーズする場合があります** → OStim を動作確認バージョン（7.5.1b 以上）に更新してください。
- **クエストに関わる重要NPCは、甘屍招来で蘇生できないようにしています**（ゲーム本体側の不具合・セーブ破損を防ぐため）。
- **甘屍招来（生者化）＋フォロワー化MODの併用について**：甘屍招来で生き返らせたNPCを、別のフォロワー管理MODでフォロワーにした場合、その相手が**山賊などの野良（本来は敵対勢力の）NPC**だと、本来の再出現（リポップ）のタイミングで**味方として現れてしまうことがあるかもしれません**。**原因はまだはっきり特定できていません**（フォロワー管理MOD側との相互作用が疑わしいものの、断定はできていません）。気になる場合は、そうした野良NPCの生者化＋他MODでのフォロワー化は控えめにしてください。

## 不具合報告のしかた
不具合に遭遇したら、MCMから診断ファイルを作って送っていただけると、原因の特定が早まります。
1. MCM →「**デバッグ**」ページを開きます。
2. 「**不具合報告ファイルを作成**」の「**実行**」を押します。
3. `ASTR2_BugReport.txt` が **SKSEログフォルダ** に作られます。**正確な場所は、押した後にMCMの「格納場所」に表示されます**（フォルダ名は環境で変わるので、必ずそこで確認してください）。
4. そのファイルを、不具合の内容（何をした時に起きたか）と一緒に送ってください。

中身は、サキュバスの状態（覚醒・レベル・淫魔力）・主要な設定（ボディ判定など）・OStimのバージョン・**必須MODのロード有無**といった、切り分けに必要な情報だけです（個人情報は含みません）。
※クラッシュ（CTD）の場合は、クラッシュログ（Crash Logger SSE 等を導入していれば生成されます）も一緒に添えてもらえると助かります。

## 互換性について
本MODは、**作者が個人用に開発したものを公開している**ものです。そのため、**他のMODとの相性・競合については十分に検証できていません**。OStim系のMODと共存する前提で作っていますが、あらゆるMOD環境での動作を保証するものではありません。競合が疑われる場合は、環境を切り分けてご確認ください（不具合の報告は歓迎します）。

**ゲームバージョンについて**：本MODは **1.6.1170** と **1.7.104** の両方に対応しています（同じファイルでどちらでも動きます）。**1.6.1170** を引き続き推奨します。**1.7.104** でも動作は確認しましたが、十分に検証できたとは言えないため、不具合が見つかった際はご報告いただけると助かります。前提MOD（OStim / SKSE / Address Library 等）は、**1.6.1170** では下記 Requirements の版を、**1.7.104** ではお使いの環境に合った版をご使用ください。
